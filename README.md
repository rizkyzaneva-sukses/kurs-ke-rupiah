# Kurs ke Rupiah

Aplikasi Android sederhana untuk mengubah mata uang asing ke Rupiah (IDR), dibuat untuk membantu usaha import/ekspor.

## Fitur
- **Kurs:** ketik nominal, hasil Rupiah langsung muncul. Ada 8 mata uang favorit dan pencarian 165 mata uang. Tetap jalan offline memakai kurs terakhir yang tersimpan.
- **Harga:** hitung harga jual dari modal dan target margin (margin dan markup ditampilkan), atau margin dari harga jual, plus mode ekspor.
- **Pantau:** grafik kurs 30 hari dan notifikasi saat kurs melewati batas yang kamu atur.
- **Riwayat:** simpan perhitungan dengan catatan supplier/barang.

## Pasang
1. Buka halaman [Releases](../../releases/latest) lalu unduh `KursKeRupiah.apk`.
2. Buka file di HP dan izinkan "pasang dari sumber ini" jika diminta.

## Update
Di dalam aplikasi, buka ⚙ lalu tap **Cek update**. Jika ada versi baru akan muncul tombol **Update**, aplikasi mengunduh dan membuka pemasangnya. Tidak perlu uninstall.

> Repo ini hanya berisi README dan file rilis (APK + `version.json`). Tidak ada kode rahasia atau kunci penandatangan.
